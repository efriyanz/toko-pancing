# toko-pancing
## Rencana fitur

- Landing page dan katalog produk (publik, tanpa login)
- Keranjang dan checkout sebagai tamu
- Login karyawan dengan role (admin, sales, kasir)
- Dashboard penjualan: ringkasan, produk terlaris, stok menipis
- Kelola produk, stok, dan pesanan online
- Aplikasi kasir yang memanggil API

## Teknologi

- Backend: Laravel, Laravel Sanctum, MySQL
- Frontend: HTML, CSS, JavaScript, Vue
- Alat: Git, GitHub, Postman
